# Nexora Business Performance & Revenue Analytics

Responsive React + Vite + JavaScript dashboard styled with SCSS. This project uses sample data only and does not require a backend.

## Run locally
1. Install Node.js LTS.
2. Open this folder in VS Code.
3. Run `npm install`
4. Run `npm run dev`
5. Open the localhost URL shown in the terminal.

## Build/deploy
Run `npm run build`. Deploy the repository to Vercel or Netlify with build command `npm run build` and output folder `dist`.

Interactions included: sidebar active state, date range controls, searchable service/team tables, and CSV export. The user/department selectors are currently UI controls with demo data, not backend filters. All metrics are sample values; verify and tune them before submission.
